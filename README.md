# 📌 Project Overview

This project develops an AI-powered Sentiment Analysis System using Natural Language Processing (NLP) and Machine Learning techniques on real-world Amazon customer reviews.

The system analyzes customer review text and automatically classifies sentiments as:

- ✅ Positive Review
- ❌ Negative Review

The project includes:
- data preprocessing,
- exploratory data analysis,
- NLP text cleaning,
- TF-IDF feature engineering,
- machine learning model training,
- evaluation metrics,
- and interactive sentiment prediction.

The complete workflow demonstrates how AI and NLP techniques can be applied to solve real-world business and customer feedback analysis problems.

# 🧹 NLP Text Preprocessing

The following NLP preprocessing techniques were applied:

- Lowercase conversion
- Punctuation removal
- Stopword removal
- Text cleaning
- Tokenization
- Feature extraction using TF-IDF

These preprocessing steps improved the overall quality and performance of the sentiment classification model.

---

# 🤖 Machine Learning Model

### Model Used:
- Logistic Regression

### Feature Engineering:
- TF-IDF Vectorization

### Train-Test Split:
- 80% Training Data
- 20% Testing Data

The Logistic Regression model was trained on TF-IDF-transformed review text data to classify customer sentiments effectively.
